# Boros PhD Archive

A consolidated, private archival copy of the legacy Active Foam and Active Foam - Backup code. This is a historical archive, not a ready-to-run MATLAB package.

## Contents

- 492 files are listed in the tree below; MATLAB .asv autosaves are excluded from the tree and ignored by Git.
- 484 MATLAB .m files and 3 Python .py files are included in the tree.
- AF - Backup Duplicates/README.md records 190 exact duplicate files that were not copied into that folder.
- AF - Backup Variants/ contains 9 files whose contents differed at a matching relative path.
- Velocity Calculation/Scripts/ is retained. Velocity Calculation/Functions/ contains only a README pointing to the separate 3D PIV repository; https://github.com/rgb-physics/MATLAB_3D-PIV.

## Archive notes

- The Chan-Vese folder and contents, ChenVese_Extracted.m
- Absolute paths in .m files were redacted. Session and Exp identifiers remain in path-derived values as reference metadata; some values are empty where neither identifier was present.
- MATLAB autosave files remain in the local folder but are excluded by .gitignore and omitted from this tree. Confirm they are not staged before pushing.
- README_dependencies.txt lists gfilter. Other external-library references are present in source comments and should be reviewed before public release.
